## Design Context

### Users
primarily me and a few friends. steam deck is the aspirational target but macos desktop is the daily driver during development. usage context: couch gaming, low light, controller in hand.

### Brand Personality
cozy, clean, rounded. like a warm game room — not sterile, not maximalist. comfortable to spend time in.

### Aesthetic Direction
- dark base from existing shadcn tokens (already in app.css)
- steam big picture as usability reference (full-screen controller navigation, large targets, no pointer required) but visually more distinctive
- xbox dashboard as interaction reference (horizontal carousels, game tiles, clear hierarchy) but with softer rounded corners throughout
- explicitly NOT prism launcher (too dense, too many panels, desktop-first)
- warm undertones rather than cold/blue defaults

### Design Principles
1. **Controller-first, not controller-also** — every interactive element is reachable via d-pad. pointer is optional.
2. **Cozy precision** — rounded corners, warm color temperature, generous spacing. feels like a game console, not a file manager.
3. **One screen at a time** — no multi-panel dashboards. each view is self-contained and fills the space.
4. **Big targets, calm palette** — large buttons and cards with comfortable whitespace. no neon, no harsh contrasts.
